# 🌐 My Digital Portfolio


---

## 📖 Tentang Project Ini
Selamat datang di **Digital Space** saya! 
Repository ini berisi *source code* dari website portofolio pribadi yang saya bangun dari nol (*from scratch*). Website ini dirancang sebagai "rumah" untuk mendokumentasikan perjalanan belajar saya, memamerkan hasil karya, dan menunjukkan kemampuan saya dalam pengembangan web.

## 🛠️ Teknologi yang Digunakan
Project ini dibangun tanpa bantuan *framework* CSS (seperti Bootstrap/Tailwind) untuk memastikan saya benar-benar memahami konsep dasar:
- **HTML5:** Untuk struktur konten yang rapi dan semantik.
- **CSS3:** Untuk styling, layouting (**Flexbox & Grid**), dan animasi.
- **Git & GitHub:** Untuk manajemen versi dan hosting (GitHub Pages).

## ✨ Fitur Utama
- **Desain Responsif:** Tampilan otomatis menyesuaikan ukuran layar (HP, Tablet, Desktop).
- **Navigasi Simpel:** Memudahkan pengunjung menjelajahi profil dan karya saya.
- **Showcase Project:** Bagian khusus untuk menampilkan project-project coding saya (menggunakan elemen interaktif `<details>`).
